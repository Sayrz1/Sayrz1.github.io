    Lunar Navigator

    NASA Space Apps Challenge 2026, team project

    A web app for choosing where and when to land on the Moon. Pick a site, such as Apollo 11 or an Artemis III candidate near the south pole, and a date. It shows when the Sun sets behind the terrain and when Earth drops out of radio contact.

    • Real horizons from NASA LOLA terrain, traced along 720 directions around each site in a Web Worker so the page never freezes
    • Sun and Earth positions from astronomy-engine, checked against the NASA JPL Horizons REST API to within 0.003°
    • A Python pipeline (NumPy, Pillow) that turns raw NASA PDS terrain files into tiles the browser can stream
    • A year-ahead landing calendar, battery estimate, Canvas charts, an "Ask Navi" question box and a full Arabic version
    • JavaScript

    LexiLift

    Final year project, NLP

    A Chrome extension that rewrites any web page into simpler English at a CEFR level you choose (A2, B1 or B2). Nothing is sent to the internet: a local FastAPI backend serves the models.

    • Fine-tuned six models with Hugging Face Transformers and PyTorch: T5-small and BART-base, each on raw, BERTScore-filtered and NLI-filtered data, tuned with Optuna on CUDA GPUs
    • Built the training set by combining ASSET, Newsela and TurkCorpus, with pandas profiling reports for every filter step
    • The deployed T5 model scores 56.43 SARI and changes numbers in only 0.60% of outputs, backed up by a human evaluation
    • A meaning gate compares sentence embeddings (sentence-transformers) and rejects rewrites that drift too far
    • A FastAPI and Pydantic backend with a result cache, a Chrome MV3 extension, and an ONNX export that runs 1.5 to 2 times faster on CPU
