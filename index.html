Final year project, NLP

LexiLift

A Chrome extension that rewrites any web page into simpler English at a CEFR level you choose (A2, B1 or B2). Nothing is sent to the internet: a local FastAPI backend serves the models.

  • Fine-tuned six models: T5-small and BART-base, each on raw, BERTScore-filtered and NLI-filtered data
  • The deployed T5 model scores 56.43 SARI and changes numbers in only 0.60% of outputs
  • A meaning gate rejects rewrites that drift too far, and an ONNX export runs 1.5 to 2 times faster on CPU
  • Python
  • PyTorch
  • Transformers
  • FastAPI
  • ONNX
  • Chrome MV3
